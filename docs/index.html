What it does

Tell it what you need.

The pane is a conversation. Type /review, /fix, /dashboard, or just say it: "check this sheet", "pie of revenue by region". It works out where the table is, what's wrong with it and what's worth charting, and shows you before it changes anything.

It isn't an AI. There's no model, no API key and no network call: commands are read against a fixed list, so the same words always do the same thing, and nothing you have is sent anywhere.

Check for mistakes

The errors that quietly make a report wrong, found and marked in the sheet itself: red for errors, amber to check, blue for tidying.

  • A typed-in number among formulas, which stopped updating
  • A total whose SUM stops short of the rows beside it
  • Amounts and dates stored as text, so they never add up
  • An ID used twice, naming the row it clashes with
  • The same name spelled two ways, splitting every chart
  • Values far outside the rest, and dates years out

Jump to any cell, fix a whole kind in one click, or ignore it for good. Outliers and duplicate IDs are reported without a fix, because only you know which row is wrong.

Marks are borrowed, not taken: each cell's own fill is remembered first, so clearing them puts your formatting back. And undo is ours, not Excel's: every fix snapshots the cells, so they come back exactly as they were.

Build a dashboard

MEx reads what each column holds and suggests up to eight charts that together tell the story: the trend over time, a comparison, a share, a two-way breakdown, a top 10, a relationship. Every one comes with the reason it was suggested.

You decide what goes in. Say "build 1, 2 and 5", "only the first four", or ask for your own: "add a doughnut of Units by Channel". Choose which columns it may use, and how many charts you want. Nothing is fixed.

It works straight from a messy export and never adds up prices or percentages. Colours stay the same for the same thing in every chart. The dashboard is saved in the workbook: next month, paste in the new rows and say refresh - charts find their columns by name, so a new export with them in another order still works.

Up to 8 charts, 4 headline numbers, one tidy grid. The numbers behind every chart go on a companion sheet so you can check them.

Do this month's work again next month

The expensive part of a monthly report isn't the thinking, it's the repetition: the same clean-up, the same combine, the same dashboard, in the same order, from a file with the same shape and different numbers.

So MEx remembers. Every command that works is recorded as you go — there's no mode to switch on — and /recipe save month end keeps the sequence. Next month, one line runs the lot.

What's stored is the command, not the result. "Clean up this sheet", not "clean A1:F250" — so a recipe still works when the sheet is four hundred rows longer. If a step needs a sheet this workbook hasn't got, it's skipped and named rather than pointed at whatever sheet looks similar.

Recipes live inside the .xlsx, like the dashboards do. Send the file to a colleague and their copy of MEx can run the same routine. No account, no server, nothing to sync.

Find every difference between two sheets

"Last month's file and this month's disagree by 412 and I can't find where." MEx matches the rows on a key column and reports every cell that moved, with both values and the amount of the change — plus the rows that appeared and the rows that went away, kept separate, because a missing row and an edited row need different explanations.

Numbers are compared with a tolerance, so a figure rounded to the penny in one export and not the other isn't reported as a difference. Rounding noise is silence; real movement is a line in the report.

The differences go on their own sheet, ready to send to whoever asked, and the changed cells are highlighted in the newer sheet so you can go and look.

If no column is unique enough to match rows on, MEx says so and compares whole rows instead — which finds what was added and removed, but not what was edited. It tells you that rather than quietly reporting less.

Get started

Install it in about a minute.

It's free, there's no account, and nothing to pay for. Pick the line that matches where you use Excel.

Excel on Windows

One line

Open PowerShell from the Start menu, paste this in and press Enter. It installs for your user account only — no administrator rights, nothing machine-wide.

> irm https://mex-automate.vercel.app/install.ps1 | iex
  1. Close Excel if it's open
  2. Run the line above
  3. Open Excel — Home › Automate

Excel on the web

Download manifest.xml
  1. Open any workbook at excel.new
  2. Home › Add-ins › More Settings
  3. Choose Upload My Add-in and pick the file you just downloaded

Excel on a Mac

Download manifest.xml
  1. In Finder press ⌘⇧G
  2. Go to ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef
  3. Drop the file in there, then restart Excel
On Windows, but you'd rather not run a script

Excel on Windows can also load an add-in from a folder you've told it to trust. It's more clicks, but there's no script involved.

  1. Download manifest.xml into a new folder, say C:\MEx.
  2. Right-click that folder, choose Properties › Sharing › Share, and share it with yourself. Copy the network path it shows you — it looks like \\YOUR-PC\MEx.
  3. In Excel go to File › Options › Trust Center › Trust Center Settings › Trusted Add-in Catalogs. Paste that path, click Add catalog, tick Show in Menu, and press OK twice.
  4. Restart Excel, then go to Home › Add-ins › Advanced and pick Shared Folder. MEx Automate is listed there.
What the installer actually does, and how to remove it

The Windows installer is a short, readable PowerShell script. You can read it first — it's about a hundred lines and half of them are comments. It does two things:

  1. Downloads manifest.xml — a small XML file naming the add-in and where its pane lives — into %LOCALAPPDATA%\MEx Automate.
  2. Writes one registry value under HKCU\Software\Microsoft\Office\16.0\WEF\Developer so Excel knows to load it. HKCU means your user account only.

To remove it, run irm https://mex-automate.vercel.app/uninstall.ps1 | iex. That deletes both. Any sheets, dashboards and formulas MEx built stay put — they're ordinary Excel content, and they keep working with the add-in gone.

Why isn't this in the Add-ins store yet? It hasn't been submitted to AppSource yet — that listing is still being prepared. Installing a manifest directly, as above, is how Microsoft has you load an add-in that isn't in the store; the web and Mac routes are straight out of their own instructions. When the listing does go live, installing will be one click from inside Excel and this page will change to say so.

Questions

Before you install.

How messy can the data be?

Very. MEx finds the real headings even below a title and a "Generated by" line, removes subtotal, grand total, blank and repeated heading rows, turns group headings into a column, and reads numbers and dates however they were typed, including European decimals, brackets for negatives, and SAP-style trailing minus signs. You see everything it found, with examples, before anything changes.

Will it change my original data?

No. Fix messy data and Build a dashboard put their results on new sheets and leave your export exactly as it was. The smaller tools that do edit in place, like Quick clean-ups, show exactly which cells they're about to change first.

How does Refresh work?

A dashboard is saved inside the workbook along with the sheet it was built from. When next month's rows arrive, paste them into that sheet and click Refresh: every chart and headline number is rebuilt from the new data in the same layout. Charts find their columns by name, so it still works if the columns come in a different order.

Is this AI? What does it cost to run?

No, and nothing. MEx reads a fixed set of commands, so the same words always do the same thing and there's no model to be wrong. There's no API key, no subscription and no server: nothing you type or open is sent anywhere.

Can I choose what goes in a dashboard?

Yes. The suggestions are a starting point: keep them all, name the ones you want ("build 1, 2 and 5"), cap how many it suggests, limit it to certain columns, or describe your own chart - "add a doughnut of Units by Channel". You can also change your mind later and just build another.

Which versions of Excel does it work with?

Excel 2019 or later on Windows and Mac, Excel in Microsoft 365, and Excel on the web.

Can I undo a change?

Excel's Undo may not reverse every change an add-in makes, so for a workbook that matters, save a copy before a big edit. The two main tools never edit your original sheet, so there's nothing to undo there.

Does it need macros or the internet?

No macros: it's built on Microsoft's modern add-in platform. Excel loads the add-in itself from the web when you open it, like any Office add-in, but your spreadsheet data is never sent anywhere.

Is it really free?

Yes. There's no trial, no subscription and no account.
